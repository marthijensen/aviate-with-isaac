A simple setup guide for authorized team members using Tableau, Power BI, DBeaver, or other PostgreSQL clients.

Access is restricted. This account can read records, including potentially sensitive student and financial information. Do not publish, forward, or store the password in source code. Request it privately from the project administrator.

Connection details

Before you connect

  1. Confirm you are authorized to access project data.
  2. Request the shared read-only password through a secure channel.
  3. Use a PostgreSQL connection and require SSL.
  4. Never use the Supabase administrator password.

Choose your application

  1. Open Tableau and choose Connect → PostgreSQL (install the driver if prompted).
  2. Enter the server, port, database, username, and password shown above.
  3. Require SSL for the connection.
  4. Sign in and select the tables needed for your analysis.
  1. Open Power BI Desktop → Get Data → PostgreSQL database.
  2. Enter server as aws-0-us-west-2.pooler.supabase.com:5432 and database as postgres.
  3. Choose database credentials and enter the read-only username and password.
  4. Ensure the connection uses encrypted SSL and select tables to load.

Power BI on macOS generally requires a Windows environment or a supported alternative.

  1. Open DBeaver → New Database Connection → PostgreSQL.
  2. Choose Host and enter the connection fields above.
  3. Under SSL, set SSL mode = require.
  4. Click Test Connection, then Finish.

Use your tool's PostgreSQL connector with the host, port, database, username, and password above. Require TLS/SSL. Keep credentials in a secure secret store rather than committed files.

Quick connection test

After connecting, run this read-only SQL query:

SELECT current_user;

Expected result: readonly_user.

Troubleshooting

Tenant/user not found: Confirm the username includes the exact project suffix.

No route to host: Use the IPv4-compatible session pooler shown above, not the direct db. host.

SSL root certificate error: Check that SSL mode is require, not verify-ca without a configured CA certificate.

Zero rows: Contact the administrator to check RLS policies and access.
